# 桌面数字生命体与环境外脑 (Gemini-S1 Cyber-Familiar & Ambient Brain)
> **OpenVela Contest 2026 最终产品设计规格与开发规划方案**

---

## 一、 产品定位与核心哲学

* **产品定位**：物理容器式桌面数字生命体与环境外脑（Ambient Cyber-Familiar & Personal Second Brain）。
* **第一性原理**：跳出“单一眼睛/木鱼”的具象限制，回归一台常驻桌面、拥有“全彩微屏 + 双麦拾音 + 触觉马达 + 物理传感 + 局域网Web”的物理终端。
* **架构哲学**：
  > **“硬件是躯壳（Hardware Vessel），卡带是心智（Agent Cartridge），网络是纽带（Companion Link）。”**

## 二、 系统全局交互与界面规范（小屏定制）

针对 2.4 ~ 3.5 寸小屏（320x240 / 480x320），杜绝传统复杂多级树形菜单，采用**“舞台 + 抽屉 + 胶囊”**的三层无感交互：

```text
┌────────────────────────────────────────────────────────────────────────┐
│ 1. 顶部微胶囊 (24px): 默认透明隐形；断网/录音/思考/倒计时时浮现呼应    │
├────────────────────────────────────────────────────────────────────────┤
│                                                                        │
│ 2. 主舞台视窗 (Stage): 当前装载的场景卡带全屏渲染                     │
│    - 左右滑动手势 / 桌面三连击: 60fps 平滑滑动轮换不同卡带              │
│                                                                        │
├────────────────────────────────────────────────────────────────────────┤
│ 3. 下拉控制抽屉 (Swipe Down): 呼出端侧【设置菜单与控制中心】           │
│    - Wi-Fi/IP 状态、热点配网触发、Web服务开关、传感器物理开关、音量亮度│
└────────────────────────────────────────────────────────────────────────┘
```

### 多模态物理语义
* **桌面微震敲击（Knock Sensing）**：
  - 键盘敲击微震：触发萌宠“伴读打字”状态；
  - 单次轻敲（Single Knock）：木鱼敲击 / 翻页钟切换显示；
  - 快速双敲（Double Knock）：灵感胶囊立即开始 5s 录音；
  - 快速三敲（Triple Knock）：无触控切换下一个卡带。
* **触觉震动马达语义（Haptic Grammar）**：
  - `HAPTIC_CLICK`（5ms 单脉冲）：触控微反馈；
  - `HAPTIC_PURR`（连续 20ms 低频）：抚摸萌宠打呼噜；
  - `HAPTIC_HEAVY_THUD`（30ms 钝击）：木鱼敲击、翻页钟整点机械打簧；
  - `HAPTIC_DOUBLE_PULSE`（双脉冲）：语音记录完成、番茄钟提醒。

## 四、 四大核心卡带（Cartridge）功能矩阵

### 1. 卡带 1：桌面使魔与治愈萌宠（Cyber Familiar）
* **定位**：高情绪价值的案头生命体，代码伴侣。
* **行为状态机**：
  - `SLEEPING`：夜间/暗光下拉被子睡觉，伴随微弱呼吸光；
  - `PATROL`：待机左右巡逻、吹泡泡、看书；
  - `TYPING_COMPANION`：敲键盘微震触发，萌宠同步搬出小电脑打字；
  - `HAPPY_PURR`：屏幕触摸抚摸，眯眼摇尾巴并触发打呼噜微震；
  - `SURPRISED`：重击桌子吓一跳弹出气泡。
* **记忆与心智**：Web 端自由定制性格、语气与人设，本地保留 20 条近期闲聊记忆。

### 2. 卡带 2：桌面环境外脑与灵感胶囊（Ambient Second Brain）
* **定位**：免手操外挂记忆体，随口捕获闪念与待办。
* **极速捕获流**：
  - 免唤醒词随口说（“记一下……”）或轻敲两下，主屏升起实时音频波形示波器；
  - 端侧意图提取：自动划分为 `TODO`（待办）、`IDEA`（灵感）、`REMINDER`（即时提醒）；
  - 本地循环闪存存储（断网仍可存 200 条）；
  - 局域网 Web 实时同步为 Trello/Notion 风格看板，支持导出 Markdown。

### 3. 卡带 3：拟物时钟与微气象（Ambient Timepiece & Weather）
* **定位**：极客桌面艺术品，拟物与自然环境共鸣。
* **核心功能**：
  - **机械翻页钟（Flip Clock）**：LVGL 拟真机械翻牌动效，整点打簧微震与清脆滴答音；
  - **真实天气拟态**：根据网络气象在屏幕边缘模拟细密雨滴凝聚滑落；
  - **暗夜煤油灯**：光敏传感器感知暗光，自动转为琥珀色烛火粒子拟态；
  - **物理解压签筒**：摇晃设备 3 次触发重力摇签，滑出赛博极客每日一签。

### 4. 卡带 4：极客禅意与赛博木鱼（Cyber Zen & Focus Guardian）
* **定位**：解压专注与心流护航。
* **核心功能**：
  - **功德木鱼**：真实木鱼/机械键盘音效敲击，浮动功德动效；
  - **心流番茄钟**：极简倒计时呼吸光环，敲击即开即停；
  - **本地功德与专注热力图统计**。

## 五、 端侧控制中心（Control Center Drawer）功能列表

通过**屏幕顶部下滑**或**双指长按 1.5s** 呼出：
1. **网络连接状态**：当前 Wi-Fi 名称、分配到的内网 IP、`[开启热点配网]` 按钮；
2. **Web 伴侣服务**：一键开启/关闭 HTTP 服务，高亮提示当前访问地址（省电与安全）；
3. **硬件感知开关**：敲击感应开关、麦克风拾音开关、触觉马达（强/弱/关）；
4. **系统显示声音**：音量滑动条、屏幕亮度滑动条、`[恢复出厂]` 按钮。
