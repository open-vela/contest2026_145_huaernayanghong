# OpenVela 小屏显示与触控交互开发指南

本指南涵盖 OpenVela Framebuffer 显存驱动架构、`getevent` 触控与按键调试工具使用、以及专为 2.4 ~ 3.5 寸小屏定制的“舞台 + 抽屉 + 胶囊”三层轻量交互界面与 LVGL 9 / QuickApp 动效实现方案。

---

## 1. Framebuffer 架构与设备节点

OpenVela 图形子系统基于 Linux 风格的虚拟文件系统 VFS 抽象显存驱动：
* **帧缓冲显存节点**：`/dev/fb0`
* **触控屏输入节点**：`/dev/input0`
* **物理按键输入节点**：`/dev/kbd0`

### 1.1 显存大小计算与色彩格式
对于 Gemini-S1 2.8 寸屏（典型分辨率 $320 \times 240$）：
* **RGB565 (16bpp)**：$320 \times 240 \times 2 = 153,600$ 字节（约 150 KB，嵌入式推荐，兼顾显存占用与 SPI 刷新带宽）
* **ARGB8888 (32bpp)**：$320 \times 240 \times 4 = 307,200$ 字节（约 300 KB）

## 2. 终端触控与按键调试：`getevent`

OpenVela 预装了 `getevent` 工具，用于在没有图形界面的串口终端下直接监听底层硬件事件。

### 2.1 常用监控命令
```bash
# 1. 自动发现并监控板端所有输入设备
getevent

# 2. 仅过滤监控触摸屏点击与滑动事件 (上报 X, Y 物理坐标与触控压力)
getevent -t /dev/input0

# 3. 仅监控物理按键 (按下/抬起键码)
getevent -k /dev/kbd0
```

### 2.2 触控旋转与校准排查
若触控坐标与屏幕显示方向不一致（如横屏点击对应竖屏位置），需在触摸驱动层或 LVGL 端口层设置坐标变换：
```c
/* 在触控回调函数中根据屏幕旋转角度交换/翻转坐标 */
data->point.x = raw_y;
data->point.y = HOR_RES - 1 - raw_x;
```

## 3. 小屏专用“舞台 + 抽屉 + 胶囊”三层无感交互规范

在 320x240 等小屏设备上，应彻底摒弃复杂的桌面树状多级菜单，采用以下三层空间架构：

```text
┌────────────────────────────────────────────────────────────────────────┐
│ 1. 顶部微胶囊 (Top Capsule, 高度 24px):                                 │
│    - 默认状态完全透明/隐形；                                           │
│    - 仅在网络断开、麦克风录音、LLM思考或倒计时提醒时高亮滑出胶囊呼应      │
├────────────────────────────────────────────────────────────────────────┤
│ 2. 主舞台视窗 (Main Stage Viewport):                                   │
│    - 当前处于活动状态的场景卡带全屏渲染 (萌宠/时钟/木鱼/灵感看板)        │
│    - 左右滑动手势或敲击桌动效: 触发 60fps 平滑横向位移切换卡带          │
├────────────────────────────────────────────────────────────────────────┤
│ 3. 下拉控制中心抽屉 (Control Center Drawer):                           │
│    - 从屏幕顶部向下滑动呼出覆盖层；                                     │
│    - 展示实时 IP、SoftAP 热点配网按钮、Web 服务开关、音量与亮度滑条   │
└────────────────────────────────────────────────────────────────────────┘
```

### 3.1 核心 UI 文件与模块职责
* `ui/ui_stage.c / .h`：主舞台容器，管理卡带全屏视窗渲染与横向平移过渡。
* `ui/ui_capsule.c / .h`：顶部微胶囊组件，提供呼吸光晕、状态气泡与淡入淡出动效。
* `ui/ui_settings.c / .h`：下拉控制中心抽屉，提供网络与系统硬件开关。
* `ui/eye_anim.c / .h`：灵眸生命体专属眼球微表情渲染引擎。

## 4. LVGL 性能调优与 60fps 实践

全志 R528-S3 驱动 SPI 屏时，SPI 总线传输带宽是决定流畅度的核心瓶颈：

1. **双缓冲配置 (Double Buffering)**：
   - 配置两个大小为屏幕 $1/5 \sim 1/10$ 高度的缓冲区（如 $320 \times 40$ RGB565，约 25KB）；
   - 利用 DMA 在后台刷屏的同时，CPU 并行渲染下一帧，避免画面撕裂与等待停顿。
2. **严格脏矩形局部刷新 (Invalidate Area)**：
   - 避免频繁调用 `lv_obj_invalidate(lv_scr_act())` 重绘全屏；
   - 仅对微胶囊文本、时钟秒数或音量条等局部变化区域执行 `lv_obj_invalidate(target_obj)`。
3. **精简中文字库打包**：
   - 杜绝引入数兆字节的全量中文字库。使用 `lv_font_conv` 工具，提取作品所需的常用汉字（如“配网、连接、温度、功德、设置、开始”等约 300 字）和 ASCII 符号，生成专用的 `lv_font_chinese_16.c`，占用 Flash 不足 20KB。
